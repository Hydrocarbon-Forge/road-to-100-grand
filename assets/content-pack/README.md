## Posting tips ($0 distribution)

- Post 3–4x/week, not all 12 at once. Rotate the order on a second cycle.
- On X: post as-is (all fit the character limit). On LinkedIn: optionally add
  one line of personal context above the post. On Reddit: only share where
  genuinely relevant to the thread — never spam; adapt into a comment.
- End with a soft pointer at most once per week, e.g. "I put my exact
  templates in a starter kit — DM if curious." Otherwise post value with no ask.
- Track which 3 get the most replies/saves; expand the winners into longer
  posts or short videos later.
