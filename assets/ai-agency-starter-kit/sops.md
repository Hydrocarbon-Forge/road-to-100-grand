# SOPs — 5 Core Checklists (run for every client)

## SOP 1 — Onboarding (after "yes", before the scoping call)

1. Send `client-email-templates.md` #2 (welcome) with intake questions + call link.
2. Create client folder: `clients/[business]/` with `scope.md`, `content/`, `quote.txt`.
3. Confirm call time + ask for 2–3 sites they like (even rough examples).
4. Do NOT start design or code yet.

Done when: intake answers received (or call time arrived), folder exists, call confirmed.

## SOP 2 — Scoping call (60 min, $5 idea call)

Agenda (send #3 scoping email beforehand):
1. (10 min) Their #1 goal for the site — write it down verbatim.
2. (20 min) Pages + features list — build it live, client watches.
3. (10 min) Content: who provides text/photos/logo, and by when → set the deadline.
4. (15 min) Run `pricing-calculator.html` live → read the total aloud → state the timeline.
5. (5 min) Next step: "I'll send the proposal tonight; reply 'approved' and I send the agreement + deposit invoice."

Done when: scope list + quote + content deadline + timeline all written in `scope.md`, client has the numbers.

## SOP 3 — Build handoff (proposal → deposit → build)

1. Send #4 proposal email (paste calculator output), valid 14 days.
2. On "approved": send #6 (agreement + deposit invoice).
3. Start ONLY when signed agreement + deposit both complete. Confirm build slot + content deadline in writing.
4. If no content by the deadline: pause, notify kindly, resume on receipt (timeline shifts day-for-day).
5. Build; internal check against `scope.md` before showing anything.

Done when: deposit received, content received, build matches scope.

## SOP 4 — Revisions (bounded, always)

1. Deliver preview + ask for ONE consolidated list (not drips — bundle drips before starting).
2. Log each item against scope: in-scope fix vs. new request (new = quoted separately).
3. Apply round 1, confirm; apply round 2, confirm. Count aloud: "that was round 2 of 2."
4. Extra rounds: quote `$[rate]` first, get written OK, then work.
5. Get written approval of the final state before launch prep.

Done when: client approves in writing within the revision limit (or pays for extras).

## SOP 5 — Launch & support

1. Collect the 50% balance BEFORE launch (#6 remainder / #7 delivery email).
2. Launch: deploy, check mobile + forms + analytics, deliver handoff doc (hosting logins, deploy steps, how to edit text/images, third-party services).
3. Send #7 delivery email + ask for testimonial (#9 referral email after 7 days).
4. 14-day bug-fix window: scope bugs free, changes quoted. Day 15: window closes, offer care plan (#8 upsell).
5. File retrospective in client folder: what sold, what slipped, what to change in the calculator.

Done when: launched, paid in full, handoff delivered, testimonial requested, folder archived.
