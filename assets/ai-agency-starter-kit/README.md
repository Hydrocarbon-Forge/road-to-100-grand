# AI Agency Starter Kit — One-Person AI Web Dev Studio

A business-in-a-box for running a solo AI-assisted web dev agency. This is the
exact operating model behind Hydrocarbon Forge: **free pitch → $5/hr idea
calls → per-build fixed quotes → launch.**

No fluff. Every file is usable on day one.

## How to use this kit (start here)

**Day 1 — Set direction (1–2 hours)**
1. Fill in `business-plan.md`. Decide your niche (e.g., "landing pages for local trades"), your weekly outreach target, and your starting prices.
2. Open `pricing-calculator.html` in your browser. Test 3 sample projects so you can quote confidently on a call.

**Day 2 — Start pitching (1 hour/day ongoing)**
3. Follow `pitch-playbook.md`. Pick one email template and one DM template. Personalize the first two lines for every prospect — never blast identical messages.
4. When someone replies, use `client-email-templates.md` #1–#4 (lead → proposal).

**When you land a client**
5. Run SOP 1 + SOP 2 in `sops.md` (onboarding + scoping call). Quote with the calculator. Send the proposal email.
6. Before writing code: fill in `client-contract-template.md`, get a 50% deposit, then build.
7. Deliver with SOP 3–5 (handoff → revisions → launch & support). Then send the upsell / referral emails.

## The business model in 30 seconds

1. **Free pitch** — short, specific outreach showing you looked at their business. No free work, just a free idea.
2. **$5/hr idea calls** — a paid working session to turn a vague idea ("I need a website") into a defined scope (pages, features, content, timeline). The $5 rate removes friction while filtering out non-serious leads. The call fee is credited toward the build if they proceed.
3. **Per-build fixed quote** — priced from actual scope using `pricing-calculator.html`. Client knows the full price upfront. You know exactly what is (and isn't) included.
4. **Launch + support** — handoff with docs, 14-day bug-fix window, then optional paid support.

## Rules that make this work

- Never start without a signed agreement + deposit.
- Never quote from memory — always run the calculator on the call.
- Every scope has a revision limit (default: 2 rounds). Extra revisions are billed.
- You sell outcomes (bookings, sales, credibility), not tech stacks.
- Track everything: pitches sent, replies, calls booked, close rate. A simple spreadsheet beats any CRM at this stage.

## Suggested tool stack ($0 cost)

- Code: VS Code + Git + GitHub (free tier)
- Hosting: Cloudflare Pages / Netlify / Vercel (free tiers) or shared hosting the client pays for
- Email: your existing email + free tier of a mail provider
- Calls: Google Meet / Discord / Jitsi (free)
- Proposals/invoices: Markdown → PDF, or free invoicing tools
- AI assistance: any free-tier coding assistant to speed up scaffolding, boilerplate, and debugging — you review and own all output

## FAQ

**Do I need to be an expert developer?**
You need to reliably ship simple marketing sites, landing pages, and basic integrations, and know when to say no to projects beyond your level. The SOPs help you scope honestly.

**Why $5/hr idea calls instead of free consults?**
Free consults attract tire-kickers and scope-creep. $5 is cheap enough that real prospects say yes, and serious enough that time-wasters self-filter. It also frames you as a builder, not free advice.

**How fast can I launch this?**
Most people can fill in the business plan, customize the templates, and send their first 5 pitches in one weekend.
